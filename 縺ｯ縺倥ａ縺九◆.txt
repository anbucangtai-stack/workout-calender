筋トレカレンダー スマホかんたん更新版

更新内容：ChatGPTの回答をJSON以外の普通の文章でも取り込めるようにした版です。

GitHub Pagesへの更新手順
1. ZIPを展開します。
2. GitHubの workout-calender リポジトリを開きます。
3. Add file > Upload files を選びます。
4. このフォルダ内の5ファイルをアップロードします。
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon.svg
   - はじめかた.txt
5. Commit changes を押します。
6. 数分待って公開サイトをPCで開き、Ctrl+F5で再読み込みします。

注意：このサイトはChatGPTに自動接続しません。ChatGPTの相談文をコピーし、ChatGPTでメニューを作り、その回答をサイトに貼り付けて登録します。APIキーは不要です。
